# Bike Poetry Fade Club

A Birchville street-fighting game with music by Dr. 2PENZ.

**Play:** https://drewbrowntechloc.github.io/bike-poetry-fade-clu/

- Works on phones (Game Boy view upright, arcade view sideways), computers, and game controllers.
- Add it to your home screen to play it like an app and keep your records.

Listen: [Spotify](https://open.spotify.com/artist/1qOfoAt81iuP6KwpCA3KRV) · [YouTube](https://www.youtube.com/channel/UC739AiEnD95NKvZuCIwZv-w)

## Files
- `index.html` — the game
- `art/` — fighter artwork, loaded when a fighter is picked
- `music/` — the soundtrack
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — home-screen app support
